# Canvas Facilitator

Nederlandstalige desktopapp (Windows/macOS) die in maximaal 15 minuten een AI-idee via een gesproken gesprek uitwerkt tot een vijf-stappencanvas: **KIES → MEET → BEGRENS → REALISEER → VERANKER**.
